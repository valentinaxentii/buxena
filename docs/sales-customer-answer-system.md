# BUXENA customer-answer system

Use this structure for every product page, proposal and customer conversation. It answers the questions a buyer should not have to chase down: what the package costs, what is included, what the customer needs to arrange, and what the complete project needs.

## Fact rule

Only state a model-specific price, inclusion, delivery date, assembly duration, electrical requirement, warranty term, return/cancellation policy or optional service when it is verified for that model and commercially approved. Otherwise use **TBD / confirmed in written proposal**. Never borrow an answer from a competitor or another model.

## Product knowledge record — complete once per model

| Customer answer | Current record | Required source / owner |
| --- | --- | --- |
| Complete package price | TBD — approved retail and package scope | Founder / pricing approval |
| Exact inclusions | TBD — itemized supplier/manufacturer scope | Supplier document |
| Customer responsibilities / exclusions | TBD — model and project exceptions | Supplier / operations |
| Delivery timing | TBD — configuration, availability and destination | Operations / supplier |
| Assembly expectation | TBD — manual or installer scope | Supplier / installer |
| Foundation / site requirements | TBD — footprint, weight, access and local conditions | Supplier / site review |
| Electrical requirements | TBD — selected heater and local-code confirmation | Heater document / electrician |
| Warranty boundaries | TBD — applicable manufacturer document | Warranty document |
| Optional BUXENA services | TBD — market and capacity confirmation | Founder / operations |
| Total-project allowance/range | TBD — separate delivery, installation and site work | Sales / site review |

When a fact is verified, add it to the model's `salesFacts` frontmatter in the V2 catalogue and record the source internally. A source does not itself authorize a public price or commercial promise.

## Quote QA checklist

- [ ] Product and configuration are named precisely.
- [ ] Every inclusion is a visible line item or a verified statement.
- [ ] Delivery and installation each say included, priced, or to be confirmed.
- [ ] Site/access/foundation/electrical responsibilities are explicit.
- [ ] Any price is founder-approved and valid for the stated scope.
- [ ] Warranty wording refers only to applicable verified documentation.
- [ ] A named sales owner and clear, no-surprise next step are present.
